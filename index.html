About GKPhysics

Philosophy

First Principles First — Every tool answers: what root problem does this solve?

Simple, not simpler — Minimal design covering current needs + obvious next steps.

Trust, but verify — Every calculation has a defined verification path.

Architecture

Built with Python 3.12 + NiceGUI. SQLite for machine data.

Modular: one tool = one file. Each tool is self-contained.

Patient data stays local (HIPAA). Machine physics data is cloud-safe.

Validated across Perfexion, Icon, and Esprit.
